# Материалы для Chrome Web Store

Черновик карточки и ответов на вопросы формы публикации. Тексты готовы к
копированию; места, где нужно ваше решение, помечены `ЗАПОЛНИТЬ`.

## Карточка

**Название** (до 45 символов)

```
TaskMail — задачи из писем
```

**Краткое описание** (до 132 символов, показывается в поиске)

```
Задача с напоминанием из письма Gmail или Яндекс Почты: срок, приоритет, комментарий — и уведомление в нужный момент.
```

**Подробное описание**

```
TaskMail превращает письмо в задачу с напоминанием, не выходя из почты.

Как это работает
1. Наведите курсор на письмо и нажмите Ctrl+Shift+S — или вызовите «Создать
   задачу» правым кликом, или кнопкой в списке задач.
2. Тема, отправитель, ссылка на письмо и почтовый ящик подставляются сами.
   Останется выбрать срок и, если нужно, добавить комментарий.
3. В назначенное время придёт уведомление: открыть письмо, отметить
   выполненной или отложить.

Что внутри
• Разделы «Просроченные», «Сегодня», «Предстоящие», «Без срока», «Выполненные»
• Поиск по теме, отправителю и комментарию
• Приоритеты, быстрый выбор срока: сегодня, завтра, через неделю
• Светлая и тёмная темы
• Несколько выделенных писем — отдельными задачами или одной общей
• Предупреждение, если задача по этому письму уже есть
• Ссылка открывается в нужном ящике, даже если у вас несколько аккаунтов
• Если письмо удалили или перенесли — поиск по адресу отправителя
• Работает офлайн; синхронизация между устройствами включается по желанию

Приватность
Расширение не делает ни одного сетевого запроса. Задачи хранятся в браузере,
текст письма не сохраняется без вашего явного согласия и никогда не уходит в
синхронизацию. Разрешение на чтение истории просмотров не запрашивается.

Поддерживаются Gmail, Яндекс Почта и Яндекс 360, есть базовая поддержка
Mail.ru.
```

**Категория**: Productivity / Workflow & Planning
**Язык**: русский

## Единственное назначение (Single purpose)

```
Создание задач с напоминаниями из писем в веб-интерфейсах Gmail, Яндекс Почты
и Mail.ru и последующее напоминание о них.
```

## Обоснование разрешений

Формулировки для полей «Justification» — проверяющий читает именно их.

| Поле формы | Что писать |
| --- | --- |
| `contextMenus` | Пункт «Создать задачу» в контекстном меню на странице почты — основной способ вызова. |
| `storage` | Хранение задач и настроек пользователя в браузере. Данные никуда не передаются. |
| `alarms` | Срабатывание напоминания в назначенное пользователем время; в Manifest V3 это единственный способ отложенного запуска. |
| `notifications` | Показ самого напоминания с действиями «выполнено» и «отложить». |
| `scripting` | Внедрение скрипта разбора письма во вкладку, открытую до установки расширения: без этого пользователю пришлось бы перезагружать почту вручную. |
| Доступ к сайтам | Чтение темы, отправителя и идентификатора письма на страницах почты. Список ограничен девятью доменами Gmail, Яндекса и Mail.ru; на других сайтах расширение не работает. |
| Удалённый код | Не используется. Весь код входит в пакет, загрузки скриптов и eval нет. |

## Раскрытие данных (Data usage)

Как отвечать на вопросы формы:

* Собираются ли данные о пользователе — **нет**. Расширение ничего не
  передаёт: сетевых запросов в коде нет вообще.
* Персональные данные (адреса отправителей, тема письма) — хранятся
  **локально**, в передаче не участвуют. Синхронизация выполняется средствами
  самого Chrome по аккаунту пользователя и по желанию.
* Три обязательные галочки под формой (не продаём третьим лицам, не используем
  не по назначению, не используем для оценки кредитоспособности) — **отмечаются
  все три**, это соответствует действительности.
* Ссылка на политику конфиденциальности: страница готова в `docs/privacy.html`.
  При включённом GitHub Pages (ветка `main`, папка `/docs`) адрес будет
  `https://spbmolot.github.io/<репозиторий>/privacy.html` — его и указываем
  в форме. Рядом лежит `docs/index.html` — короткая страница о расширении.

## Проверка перед отправкой

```bash
node tests/run.mjs
powershell -ExecutionPolicy Bypass -File tools/package.ps1
```

Скрипт упаковки прогоняет тесты, проверяет манифест и собирает `dist/`.
Загружать в магазин нужно `.zip`, не папку.
