# Материалы для Chrome Web Store

Черновик карточки и ответов на вопросы формы публикации. Тексты готовы к
копированию; места, где нужно ваше решение, помечены `ЗАПОЛНИТЬ`.

## Карточка

**Название** (до 45 символов)

```
TaskMail — задачи из писем
```

**Краткое описание** (до 132 символов, показывается в поиске)

```
Задача с напоминанием из письма Gmail или Яндекс Почты: срок, приоритет, комментарий — и уведомление в нужный момент.
```

**Подробное описание**

```
TaskMail превращает письмо в задачу с напоминанием, не выходя из почты.

Как это работает
1. Наведите курсор на письмо и нажмите Ctrl+Shift+S — или вызовите «Создать
   задачу» правым кликом, или кнопкой в списке задач.
2. Тема, отправитель, ссылка на письмо и почтовый ящик подставляются сами.
   Останется выбрать срок и, если нужно, добавить комментарий.
3. В назначенное время придёт уведомление: открыть письмо, отметить
   выполненной или отложить.

Что внутри
• Разделы «Просроченные», «Сегодня», «Предстоящие», «Без срока», «Выполненные»
• Поиск по теме, отправителю и комментарию
• Приоритеты, быстрый выбор срока: сегодня, завтра, через неделю
• Светлая и тёмная темы
• Несколько выделенных писем — отдельными задачами или одной общей
• Предупреждение, если задача по этому письму уже есть
• Ссылка открывается в нужном ящике, даже если у вас несколько аккаунтов
• Если письмо удалили или перенесли — поиск по адресу отправителя
• Работает офлайн; синхронизация между устройствами включается по желанию

Приватность
Расширение не делает ни одного сетевого запроса. Задачи хранятся в браузере,
текст письма не сохраняется без вашего явного согласия и никогда не уходит в
синхронизацию. Разрешение на чтение истории просмотров не запрашивается.

Поддерживаются Gmail, Яндекс Почта и Яндекс 360, есть базовая поддержка
Mail.ru.
```

## Вкладка «Меры по обеспечению конфиденциальности»

Магазин не публикует товар, пока не заполнено каждое поле ниже. Тексты готовы
к копированию как есть.

### Описание цели (Single purpose)

```
TaskMail решает одну задачу: превратить письмо в веб-интерфейсе Gmail, Яндекс
Почты или Mail.ru в задачу с напоминанием и напомнить о ней в выбранное
пользователем время.

Расширение считывает со страницы почты тему письма, имя и адрес отправителя и
идентификатор письма, сохраняет их в браузере вместе со сроком, приоритетом и
комментарием пользователя, а в назначенный момент показывает уведомление, из
которого можно открыть письмо, отметить задачу выполненной или отложить
напоминание. Других функций у расширения нет.
```

### storage

```
В chrome.storage.local хранятся задачи, созданные пользователем, и настройки
расширения: тема письма, отправитель, ссылка на письмо, срок, время
напоминания, приоритет и комментарий. Без этого разрешения задача не пережила
бы перезапуск браузера, а напоминание не сработало бы.

Данные остаются в браузере пользователя: расширение не отправляет их никуда,
сетевых запросов в коде нет. Синхронизацию между устройствами через
chrome.storage.sync пользователь включает сам, по умолчанию она выключена.
```

### alarms

```
Напоминание должно сработать в момент, выбранный пользователем, — иногда через
несколько дней после создания задачи. В Manifest V3 фоновый service worker
выгружается примерно через 30 секунд бездействия, поэтому setTimeout для
отложенного запуска непригоден: chrome.alarms — единственный способ разбудить
расширение в назначенное время.

Расширение держит всего два будильника: один на ближайшее напоминание и один
страховочный, который сверяет очередь после сна системы или перезапуска
браузера.
```

### notifications

```
Напоминание доставляется системным уведомлением: в заголовке тема письма, в
тексте отправитель и комментарий, кнопки «Выполнено» и «Отложить», а клик по
уведомлению открывает исходное письмо. Это основной сценарий расширения —
без уведомлений напоминание не дойдёт до пользователя.

Уведомления показываются только по задачам, которые создал сам пользователь,
и только в выбранное им время.
```

### contextMenus

```
Пункт «Создать задачу» в контекстном меню — основной способ создать задачу из
письма: пользователь нажимает правой кнопкой на письме и получает окно с уже
заполненными темой, отправителем и ссылкой.

Пункт добавляется только на страницах поддерживаемых почтовых сервисов —
в documentUrlPatterns перечислены те же девять доменов, что и в разрешениях
на доступ к хостам. На других сайтах пункт не появляется.
```

### scripting

```
Разбор письма выполняет контент-скрипт, объявленный в манифесте, но он
внедряется при загрузке страницы. Если пользователь установил расширение,
когда вкладка с почтой уже открыта, скрипта на ней нет, и создание задачи не
сработало бы до перезагрузки страницы.

В этом случае расширение однократно внедряет через chrome.scripting тот же
самый файл src/content/extractor.js в ту же вкладку почты. Файл входит в пакет
расширения; код из сети не загружается.
```

### Разрешения на доступ к хостам

```
Доступ нужен только к страницам почты: mail.google.com, mail.yandex.ru,
mail.yandex.com, mail.yandex.by, mail.yandex.kz, mail.360.yandex.ru,
mail.360.yandex.com, 360.yandex.ru, e.mail.ru.

На этих страницах расширение считывает ровно то, из чего состоит карточка
задачи: тему письма, имя и адрес отправителя, идентификатор письма и
идентификатор ящика — последний нужен, чтобы позже открыть письмо в том же
аккаунте, если у пользователя их несколько.

Содержимое письма не читается и никуда не передаётся. Выделенный фрагмент
письма сохраняется только если пользователь сам поставил галочку в окне
задачи, и такой фрагмент никогда не участвует в синхронизации. Ни на каких
других сайтах расширение не запускается.
```

### Использование удалённого кода

Выбрать вариант «Нет, я не использую удалённый код» и вставить пояснение:

```
Удалённый код не используется. Весь JavaScript и CSS входят в пакет
расширения; загрузки скриптов с внешних адресов нет, eval и new Function в коде
не встречаются. Расширение не выполняет сетевых запросов вообще.
```

### Использование данных

* На вопрос о сборе пользовательских данных — расширение **не собирает и не
  передаёт** данные: всё, что создаёт пользователь, остаётся в его браузере.
* Три обязательные галочки отмечаются все: данные не продаются третьим лицам,
  не используются в целях, не связанных с назначением расширения, и не
  применяются для оценки кредитоспособности или выдачи займов.
* Ссылка на политику конфиденциальности:
  `https://spbmolot.github.io/taskmail/privacy.html`

## Что подготовить руками

* **Скриншоты — готовы**, лежат в `dist/screenshots` (1280×800, четыре штуки:
  список задач, окно создания, настройки, тёмная тема). Пересобираются
  командой `powershell -ExecutionPolicy Bypass -File tools/screenshots/make.ps1`
  — снимается настоящий интерфейс из `src`, подменяются только данные.
* **Иконка магазина** 128×128 — берётся из `icons/icon128.png`.
* **Рекламные изображения — готовы**, там же в `dist/screenshots`:
  `promo-440x280.png` (маленькое) и `promo-1400x560.png` (очень большое).
  Оба 24-битные PNG без альфа-канала, как требует магазин, и пересобираются
  той же командой, что и скриншоты.
* **Контактный адрес** в аккаунте разработчика: `taskmail.support@molotilo.digital`
  — его же нужно подтвердить по письму, иначе публикация не пройдёт.
* **Publisher display name** в аккаунте магазина: `MOLOTILO DIGITAL` — видимое
  имя издателя рядом с названием расширения. Юридические реквизиты ИП
  заполняются в настройках аккаунта отдельно и в карточке не показываются.
* **Единовременный взнос** разработчика Chrome Web Store, если аккаунт новый.

## Проверка перед отправкой

```bash
node tests/run.mjs
powershell -ExecutionPolicy Bypass -File tools/package.ps1
```

Скрипт упаковки прогоняет тесты, проверяет манифест и собирает `dist/`.
Загружать в магазин нужно `.zip`, не папку.
