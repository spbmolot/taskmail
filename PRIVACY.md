# Политика конфиденциальности TaskMail

Дата последнего изменения: 5 сентября 2026 года.

## Коротко

TaskMail не отправляет никаких данных наружу. У расширения нет ни одного
сетевого запроса, нет сервера, нет аналитики и нет сторонних библиотек. Всё,
что вы создаёте, остаётся в вашем браузере.

## Какие данные обрабатываются

Когда вы создаёте задачу из письма, расширение сохраняет:

* тему письма;
* имя и адрес отправителя;
* ссылку на письмо и на переписку;
* название почтового сервиса и идентификатор ящика (для Gmail — адрес, для
  Яндекса — числовой `uid`), чтобы открыть письмо в нужном аккаунте;
* ваш комментарий, срок, время напоминания и приоритет;
* дату создания и изменения задачи.

**Текст письма не сохраняется.** Исключение одно: если вы выделили фрагмент и
явно поставили галочку «Прикрепить выделенный фрагмент письма» в окне задачи.
Такой фрагмент хранится только на этом компьютере и никогда не участвует в
синхронизации — он вычищается из данных перед отправкой.

## Где данные хранятся

Основное хранилище — `chrome.storage.local`, то есть локальный профиль
браузера. Расширение полностью работоспособно без интернета.

Если вы включите в настройках «Синхронизировать между устройствами», задачи
дополнительно попадут в `chrome.storage.sync` — механизм синхронизации самого
Chrome, привязанный к вашему аккаунту Google. Данные передаются между вашими
устройствами инфраструктурой Google по правилам Google; авторы расширения к ним
доступа не имеют. Настройка выключена по умолчанию.

## Чего расширение не делает

* Не читает содержимое писем и не отправляет его куда-либо.
* Не собирает историю просмотров: разрешение `tabs` не запрашивается, адрес
  вкладки виден только для почтовых сайтов из списка ниже.
* Не показывает рекламу, не профилирует и не передаёт данные третьим лицам.
* Не продаёт и не передаёт данные никому — их просто некуда передавать.

## Доступ к сайтам

Расширение работает только на страницах почты:

`mail.google.com`, `mail.yandex.ru`, `mail.yandex.com`, `mail.yandex.by`,
`mail.yandex.kz`, `mail.360.yandex.ru`, `mail.360.yandex.com`, `360.yandex.ru`,
`e.mail.ru`.

На этих страницах скрипт читает только те элементы, которые нужны для карточки
задачи: тему, отправителя и идентификатор письма. Ни на каких других сайтах
расширение не запускается.

## Разрешения и зачем они

| Разрешение | Для чего |
| --- | --- |
| `contextMenus` | пункт «Создать задачу» по правому клику |
| `storage` | хранение задач и настроек |
| `alarms` | срабатывание напоминаний в назначенное время |
| `notifications` | показ самих напоминаний |
| `scripting` | внедрение скрипта разбора письма, если вкладку открыли до установки |
| доступ к сайтам почты | чтение темы, отправителя и ссылки на открытой странице почты |

## Удаление данных

Задачи удаляются кнопкой «Удалить» в списке. Полное удаление расширения из
браузера стирает и локальное хранилище. Если синхронизация была включена,
копии в `chrome.storage.sync` удаляются вместе с расширением на всех
устройствах, где вы вошли в тот же аккаунт Chrome.
