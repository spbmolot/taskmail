# TaskMail

Расширение Chrome (Manifest V3): задачи с напоминаниями из писем **Gmail** и
**Яндекс Почты** (плюс базовая поддержка Mail.ru). Правый клик на письме →
«Создать задачу» → срок, приоритет, комментарий → уведомление в назначенное
время.

## Установка

1. `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное расширение» → выбрать папку проекта.
3. Проверить, что уведомления Chrome разрешены в параметрах Windows: если ОС их
   глушит, расширение это увидеть не может — задачи останутся в списке, а на
   иконке появится счётчик.

## Сценарий

1. Задача из письма создаётся тремя равнозначными способами:
   * правый клик на письме → **Создать задачу**;
   * горячая клавиша **Ctrl+Shift+S** — наведите курсор на письмо и нажмите;
   * кнопка **«Создать задачу из письма»** в списке задач (появляется, когда
     активна вкладка почты).

   Способов три не для красоты: **Gmail и Яндекс Почта показывают на письмах
   собственное контекстное меню** и подавляют системное вызовом
   `preventDefault()`. В такие моменты Chrome не рисует своё меню, и пункта
   расширения в нём не будет ни у одного расширения — работают горячая клавиша
   и кнопка. Системное меню с пунктом «Создать задачу» появляется там, где
   почта его не перехватывает: на тексте открытого письма, на пустом месте
   страницы, а также по **Shift + правый клик**.

   Если письма выделены чекбоксами, берутся все выделенные; иначе — письмо под
   курсором, иначе — открытое письмо.
2. Откроется окно с автозаполненными темой, отправителем и его адресом, ссылкой
   на письмо, почтовым сервисом и аккаунтом. Дата и время создания сохраняются
   автоматически.
3. Срок выбирается чипами **Сегодня / Завтра / Через неделю / Выбрать дату**
   (или «Без срока»), рядом — время напоминания, приоритет и комментарий.
   По умолчанию подставлено ближайшее разумное время, поэтому задача создаётся
   в три клика: правый клик → «Создать задачу» → «Сохранить».
4. В назначенное время приходит уведомление:
   * клик по уведомлению — **открыть письмо** новой вкладкой;
   * кнопка **Выполнено**;
   * кнопка **Отложить на N мин** (интервал настраивается).

   Chrome разрешает не больше двух кнопок в уведомлении, поэтому третье
   действие повешено на клик по телу уведомления — об этом написано прямо в нём.
5. Иконка расширения открывает список: разделы **Просроченные / Сегодня /
   Предстоящие / Без срока / Выполненные**, поиск, цветные метки приоритета,
   действия «Открыть», «Найти», «+N мин», «Изменить», «Удалить».

## Что предусмотрено

| Ситуация | Поведение |
| --- | --- |
| Почта перехватила правый клик | Те же действия доступны по Ctrl+Shift+S и кнопкой в списке задач; обработчик `contextmenu` слушает в фазе перехвата, поэтому письмо запоминается даже когда меню подавлено |
| Письмо открыто или выбрано в списке | Контекст определяется по DOM: открытое письмо, строка под курсором или выделенные строки |
| Несколько выделенных писем | Переключатель «Отдельные задачи / Одна общая»; общая задача хранит список писем |
| Повторное добавление письма | Предупреждение о дубликате с кнопками «Открыть существующую» / «Всё равно создать»; ключ — аккаунт + id письма или треда, плюс мягкое совпадение по отправителю и теме без `Re:` |
| Цепочка писем | Хранятся обе ссылки, в окне задачи есть флажок «Ссылка на всю переписку» |
| Несколько аккаунтов | Аккаунт сохраняется вместе с задачей: для Gmail ссылка строится в форме `/mail/u/<email>/`, для Яндекса — с параметром `uid`. Письмо всегда открывается **новой вкладкой**: существующая вкладка почты может быть авторизована под другим ящиком |
| Письмо удалено или перемещено | Кнопка «Найти» ищет письма **по адресу отправителя** (Gmail — с `in:anywhere`, то есть включая Корзину и Спам). Тема в запрос не входит намеренно: её переименовывают в задаче, и поиск по новому названию письмо бы не нашёл |
| Нет темы или отправитель скрыт | «(без темы)» и «отправитель не определён», поля можно заполнить вручную |
| Дата напоминания уже прошла | Предупреждение в окне задачи; уведомление приходит сразу после сохранения |
| Chrome был закрыт | При запуске проверяются все наступившие сроки; накопившиеся сворачиваются в одно сводное уведомление |
| Смена часового пояса | Хранится «настенное» время: «завтра в 9:00» останется девятью утра на новом месте; в списке появляется уведомление о пересчёте |
| Уведомления запрещены | Баннер в списке, счётчик на иконке, кнопка «Проверить снова» |
| Офлайн | Всё работает локально; синхронизация (по желанию) через `chrome.storage.sync` догоняет при появлении сети |
| Перезапуск и обновление браузера | Данные в `chrome.storage.local`, миграции схемы, будильники перестраиваются при старте и обновлении |
| Текст письма | Не сохраняется без явного согласия: выделенный фрагмент прикрепляется только галочкой в окне задачи |

## Структура

| Файл | Назначение |
| --- | --- |
| `manifest.json` | манифест MV3, права, контент-скрипты |
| `src/background/index.js` | контекстное меню, сообщения, окна, уведомления |
| `src/background/collect.js` | сбор данных из вкладки и подготовка черновиков |
| `src/background/reminders.js` | планирование, догоняющие напоминания, часовой пояс |
| `src/background/notify.js` | уведомления и деградация при запрете |
| `src/background/links.js` | открытие письма с учётом аккаунта |
| `src/background/sync.js` | необязательная синхронизация с учётом квот |
| `src/background/migrate.js` | миграции схемы задач |
| `src/common/hosts.js` | единственный список почтовых хостов: из него читают фон и список задач, совпадение с манифестом сторожит самотест |
| `src/common/` | модель задачи, хранилище, настройки, время, дизайн-токены |
| `src/content/extractor.js` | адаптеры разбора DOM: Gmail, Яндекс, Mail.ru |
| `src/editor/` | окно создания и редактирования задачи |
| `src/popup/` | список задач, поиск, настройки |

## Ограничения

* **Вёрстка почтовых сервисов меняется.** Селекторы опираются на ARIA и
  `data-*`-атрибуты, обфусцированные классы Gmail (`zA`, `hP`, `gD`, `bog`,
  `adn`) — только как запасной вариант. В Яндекс 360 имена классов хешируются
  при каждой сборке (`MessagesList__root--0Sxmu`), поэтому опора — на
  `data-testid` и классы `qa-*`, которые ставятся для автотестов. Если и они не
  совпали, работает структурный разбор: адрес ищется в `title`/`mailto`, тема —
  первый текстовый узел строки после отправителя. Такой разбор помечается как
  неточный, и окно задачи показывает баннер «проверьте поля».
* Ссылка на письмо в Яндекс 360 строится как
  `https://mail.360.yandex.ru/?uid=<uid>#/message/<id>` — формат сверен с живым
  ящиком. Параметр `ncrnd` из адресной строки не переносится: это защита от
  кеширования, а не часть адреса письма.
* Ссылка вида `#all/<id>` открывается надёжно во вкладке, где Gmail уже
  загружен; «холодный» переход иногда требует повторного клика.
* Серверное выделение «Выбрать все N писем» в DOM не отражается — расширение
  видит только отрисованные строки.
* Уведомления не приходят при полностью закрытом Chrome (ограничение MV3):
  всё, что наступило, показывается при следующем запуске.
