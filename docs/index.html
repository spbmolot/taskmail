TaskMail

Расширение Chrome: письмо из Gmail или Яндекс Почты превращается в задачу с напоминанием — за три клика, не выходя из почты.

Что умеет

  • Тема, отправитель и ссылка на письмо подставляются сами.
  • Срок одним нажатием: сегодня, завтра, через неделю.
  • Уведомление в назначенное время: открыть письмо, выполнить, отложить.
  • Разделы «Просроченные», «Сегодня», «Предстоящие», «Выполненные», поиск и приоритеты.
  • Работает офлайн; синхронизация между устройствами — по желанию.

Приватность

  • Ни одного сетевого запроса: задачи хранятся в браузере.
  • Текст письма не сохраняется без явного согласия и не уходит в синхронизацию.
  • Разрешение на чтение истории просмотров не запрашивается.
